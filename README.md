# 解压捏捏实验室

可直接打开的 Three.js 互动网页：猫糕 / 菠萝鸡、局部脆壳破碎、软馅按压与拖拽、白色镂空蕾丝蛋糕垫。参考图用于风格化程序建模，未作为平面图贴入场景。

## 运行

- 解压完整文件包后，用现代浏览器直接打开 `index.html`。`app.js` 已包含 Three.js、OrbitControls、Cannon-es 和用到的 Lucide 图标，不依赖 CDN。
- 推荐通过静态 HTTP 服务器打开，以加载附带的本地脆裂音效：`python3 -m http.server 8080`，然后访问 `http://localhost:8080`。
- 直接以 `file://` 打开时，浏览器限制音频 fetch，因此自动使用 Web Audio 合成后备音。
- 需要浏览器支持 WebGL。手机可从发布的网址直接打开。

## 操作

1. 点外壳：局部破裂、露出内馅；硬度较高时需重复点同一位置，或持续按住。
2. 按住露出的内馅：逐渐凹陷；松开后缓慢回弹。
3. 拖动露出的内馅：局部随手指或鼠标拉伸，向上拖即可提起。
4. 指纹图标为捏压；旋转图标开启水平 360 度旋转；手掌图标可拖动整只玩偶，松手后重力下落并产生压扁、回弹和晃动。空白区域也可旋转视角，取景按钮恢复默认视角。
5. 选另一款或点「重来一次」：旧玩偶、碎片、破损、形变全部清除；音量开关和滑杆设定保留。

## 文件

- `index.html`、`style.css`：响应式界面。桌面右侧面板，≤760px 屏宽底部面板。
- `app.js`：已打包的浏览器运行文件。
- `main.js`：场景、相机、灯光、Pointer Events、Raycaster、重置逻辑。
- `models.js`：两款纯几何体玩偶、表面眼镜、金色植物纹和镂空蕾丝纸垫。
- `geometry.js`：一体五瓣花顶、开拱口糕体、蛋形身体、曲线冠羽。
- `softbody.js`：局部三角面壳层移除、断面侧壁、距离权重形变、弹簧阻尼回弹。
- `fragments.js`：大块曲面壳片、Cannon-es 重力与地面碰撞、3.1秒自动清除。移动端同时最多60片，桌面最多100片。
- `ambience.js`：云朵星星吊饰、整只玩偶提起和落地弹性模拟。
- `audio.js`：本地音频、随机脆裂音、落地音效、BGM循环和统一静音。
- `assets/audio/background.mp3`：用户上传的背景音乐原文件，首次点击/触摸后播放。重置和换款不重启音乐；静音时暂停，再开启继续播放；切后台暂停。此音乐不属于 CC0 素材，版权归原权利人，公开传播需自行确认授权。
- `assets/audio/chocolate-crack.mp3`：CC0 素材处理后的脆裂音。是巧克力脆壳风格的音效设计，并非真实咀嚼录音。
- `THIRD_PARTY_NOTICES.txt`：第三方软件和声音素材版权说明。

## 修改与重新打包

运行 `npm install`，然后 `npm run build`。直接修改源代码之后须重建 `app.js` 才会更新网页。

## 本次细节修订

- 猫糕恢复圆形平面轮廓；两款取消水平旋转限制，可以查看正面、侧面和背面。
- 菠萝鸡镜片曲面与镜框上缘压平，不再随额头向上翘。
- 外壳命中后先显示分叉裂纹，再脱落成组的大块曲面碎片。
- 背景增加云朵和星星吊饰，加载页只显示进度条，背景与网页一致。

- 默认脆硬度 22 / 柔软度 55，3px 拖动门槛，按下即产生初始压痕，按住快速加深，松手慢恢复。
- 猫糕统一薄荷色内芯；菠萝鸡统一淡黄色内芯。
- 表面装饰并入壳层：命中的镜框、镜片、眼睛、花芯、尾饰随壳层一起清除；完整且未命中的部位仍保留外观。
- 猫糕金边随糕体外轮廓贴合，底部金边在脸和爪前方断开；花顶为封闭连续曲面，中央黄色花芯可见。
- 菠萝鸡身体改为上窄下宽蛋形，补扇形尾羽、渐变弯曲冠羽，移除翅膀上的线条。

## 已验证

使用 Chromium + Playwright 实际执行：局部碎壳；碎片清理；持续按压；慢回弹；拖拽拉伸；音效开关；切换和重置；硬度、柔软度响应；12次连续切换的资源回收；移动端触摸；320×568、390×844、768×1024、1024×768、1440×900、1920×1080 的布局。

这是用于解压互动的局部弹性形变模拟，外壳预先三角化，碎裂沿三角面边界发生；不包含全体积软体有限元计算。背面和遮挡区域依据正面参考做风格化补全。
